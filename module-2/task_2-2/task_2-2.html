1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. You should use constants for values that never change (like 1000 mm in a meter) and use variables for values that change (like a game score). No they can not all be constants, because the program will crash if it tries to change a locked constant.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We use the strict equality operator (===) to check if they are equal. JavaScript will check their exact numerical values, and since 12.199999 === 12.2 evaluates to false, they are not considered the same.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return a value, which is either true or false. We can check them by printing the result to the console.

  6. How does the Math.random() function work, and what can it be used for?

    7. The Math.random() function generates a random decimal number between 0 (inclusive) and 1(exclusive) each time it is called. It can be used to generate random numbers, like rolling a dice.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus (%) gives you the remainder of a division. For example if you have 12 people and cars with five seats, you can fill two whole cars and have a remainder of 2 people left over ( 12 % 5 = 2 ). It is used in programming to wrap numbers around, like calculating hours on a 24-hour clock.
